# Manuscript data snapshot

These files are the machine-readable values used by the manuscript tables and figures. `SHA256SUMS.txt` is the original frozen-evidence checksum ledger; some paths in that ledger belong to the separate publication-evidence archive and are intentionally not duplicated in this compact Overleaf project. The final Overleaf ZIP has its own archive checksum supplied beside the download.

`full_test_predictions.npz` and `full_test_episodes.csv` regenerate the calibration and episode plots. The JSON files preserve detector, integrity, held-out, post-freeze multi-model, and final human-validation summaries. `hai23_process_topology.json` and `hai_process_graph.yaml` preserve the topology and configuration context used in the paper.
