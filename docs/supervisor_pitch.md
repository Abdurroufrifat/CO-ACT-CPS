# Short supervisor pitch

We will build **CO-ACT-CPS**, a human-centered security framework for a failure mode
that ordinary robust IDS research misses: an attacker can preserve an industrial AI
alarm while manipulating the explanation that guides the operator. A typed
graph-temporal model will convert HAI/SWaT telemetry into an alarm, causal hypotheses,
and calibrated uncertainty. A constrained generative model will translate only a
closed evidence bundle, while an independent process-grounded verifier checks cited
evidence, topology/physics support, alternatives, uncertainty, and permitted actions.
The system then chooses whether to explain, show evidence or alternatives, ask the
operator for context, warn, or abstain; it never controls actuators. We will evaluate
prediction-preserving explanation attacks, detector and calibration performance,
verification overhead, and—subject to ethics approval—diagnosis accuracy, unsafe
decisions, response time, workload, and appropriate reliance. This makes generative AI,
trustworthiness, cybersecurity, and human-AI collaboration central rather than added
as separate components.
