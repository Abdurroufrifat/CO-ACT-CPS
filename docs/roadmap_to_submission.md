# Roadmap to the 31 January 2027 submission deadline

The call supplied with the project states that submissions are open from 1 October
2026 through 31 January 2027. Confirm the live journal page before scheduling the final
submission.

## 29 August–6 September 2026

- Freeze RQs, primary outcomes, threat boundaries, and minimum publishable scope.
- Send the one-page protocol to the supervisor.
- Submit ethics/IRB materials immediately if human claims are essential.
- Install the repository, pass tests, and run the synthetic check.

Exit check: approved research plan and no unresolved scope inflation.

## 7–30 September 2026

- Acquire and validate HAI 23.05.
- Implement episode/file-safe windowing and explicit topology.
- Reproduce traditional and temporal baselines.
- Freeze train/validation/test manifests and primary metrics.

Exit check: reproducible HAI baseline table with five seeds.

## October 2026

- Implement full graph/physics detector ablations.
- Request/acquire SWaT and build an independent topology.
- Complete calibration, shift, latency, and root-cause evaluations.
- Begin a living systematic literature search log.

Exit check: detector contribution works on at least one dataset and replicates on the
second or the paper scope is revised.

## November 2026

- Implement adaptive prediction-preserving explanation attacks.
- Add provenance, invariant, topology-path, and counterfactual certificates.
- Compare template, unverified LLM, self-check, and independent verifier.
- Freeze verifier thresholds before final test attacks.

Exit check: integrity detection is useful at an acceptable clean false-alarm rate.

## December 2026

- If approval is active, run approved pilot, power analysis, and confirmatory human
  study; otherwise remove human-effect claims and retain the interface as future work.
- Complete policy/operator-model evaluation only with valid data.
- Run all ablations and statistical tests.
- Generate final figures/tables from scripts.

Exit check: every claimed contribution has a result and uncertainty interval.

## 1–20 January 2027

- Draft, internally review, and revise the manuscript.
- Audit citations, leakage, licenses, ethics wording, and reproducibility.
- Run the repository from a clean environment and archive hashes/configurations.

## 21–31 January 2027

- Supervisor/coauthor approval.
- Final journal-format, graphical, data/code availability, and submission checks.
- Submit before the final day to leave room for portal or metadata problems.

## Scope fallback

If ethics approval or recruitment cannot finish by December, do not rush or reuse
development data. Submit a technically focused paper on secured explanation channels
with a rigorous adversarial benchmark and describe human evaluation as future work—or
target a later venue where the complete human-centered claim can be tested properly.
